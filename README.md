# ایجنت تحلیل احساس فارسی

نسخه‌ی اولیه‌ی یک دسته‌بند سبک برای تشخیص نظر **مثبت، منفی یا خنثی** است. این نسخه بدون نصب کتابخانه‌ی جانبی اجرا می‌شود و برای نمونه‌سازی، ساخت دیتاست و استفاده به‌عنوان fallback مناسب است.

## اجرا

```bash
python3 sentiment_agent.py "کیفیت محصول خیلی عالی بود"
```

نمونه‌ی استفاده در کد:

```python
from sentiment_agent import PersianSentimentAgent

agent = PersianSentimentAgent()
result = agent.predict("پشتیبانی خوب بود ولی ارسال خیلی دیر انجام شد")
print(result.label, result.confidence)
print(result.to_dict())
```

اجرای تست‌ها:

```bash
python3 -m unittest -v
```

## آموزش مدل با داده

فایل `data/reviews.csv` شامل ۱۰۰۰ نظر مصنوعی و دو ستون است:

- `text`: متن نظر مشتری
- `label`: یکی از مقادیر `مثبت`، `منفی` یا `خنثی`

برای آموزش مدل:

```bash
python3 train_model.py
```

برای ساخت دوباره‌ی همین دیتاست به‌شکل قابل‌تکرار:

```bash
python3 generate_dataset.py
```

دیتاست نمونه از داده‌ی واقعی مشتریان گرفته نشده است. برای ارزیابی واقعی باید آن را با نظرات واقعی و برچسب‌گذاری‌شده جایگزین کنید.

این دستور بخشی از داده‌ها را برای آزمون کنار می‌گذارد، مدل Naive Bayes را آموزش می‌دهد و دو فایل می‌سازد:

- `models/sentiment_model.json`: اطلاعات یادگرفته‌شده‌ی مدل
- `models/evaluation.json`: دقت، ماتریس خطا و نمونه‌های اشتباه

استفاده از مدل آموزش‌دیده:

```bash
python3 predict_trained.py "کیفیت این محصول خیلی خوب بود"
```

برای بهترشدن مدل، نظرهای واقعی و برچسب‌خورده را به `data/reviews.csv` اضافه و دوباره دستور آموزش را اجرا کنید. در دیتاست واقعی بهتر است تعداد نمونه‌های سه برچسب تقریباً متعادل باشد.
